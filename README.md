**Hospital Patient Data Analysis | Microsoft Excel**

Analyzed hospital patient data of 50 patients using Microsoft Excel. Performed data analysis using Excel formulas, including age-group categorization, treatment cost calculations, and length-of-stay analysis.

Created multiple Pivot Tables to analyze department-wise patient count, total and average treatment cost, doctor-wise patients handled, gender-wise patients, insurance status, and patient outcomes.

Developed an interactive Excel Dashboard with KPI cards for Total Patients, Total Treatment Cost, Average Treatment Cost, Average Patient Age, and Average Length of Stay. Created charts for department-wise patient count, department-wise treatment cost, outcome distribution, and gender-wise patient count. Added interactive slicers for Department, Gender, Insurance, and Outcome to enable dynamic filtering and analysis.
